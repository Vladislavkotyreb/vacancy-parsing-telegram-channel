# Личный тест откликов

Тест включается только для положительного `TELEGRAM_ADMIN_ID` и только в его личном чате. Публичное меню не меняется. Вход: `/try_apply` или `/start apply_test`. Выход: `/exit_test`.

Доступны два входа: по должности (резюме требуется при первом отклике) и по резюме (текст, TXT или DOCX → проверка профиля → подборка). Вакансии, разбор профиля и письма демонстрационные, без LLM. На HH ничего не отправляется. PDF в этой версии нужно прислать текстом. Данные сессии находятся в памяти не более 30 минут; выход и перезапуск их удаляют. Сообщения остаются в самом Telegram.

## Временная установка на текущий сервер

Используйте проверенные `scripts/private_application_test.py` и `bot/application_demo.py` из одного зафиксированного коммита отдельной ветки. Из каталога действующего бота:

```sh
.venv/bin/python /path/private_application_test.py install --module-file /path/application_demo.py
```

Installer проверяет текущую версию Python и модуль до изменения файлов, сохраняет резервную копию, добавляет точечный hook в фактический серверный `chat_main.py`, включает единственный флаг в `.env` и перезапускает тот же процесс. Ветку и коммиты сервера не меняет. На время теста guard приостанавливает автодеплой; watchdog и cron рассылок остаются настроенными как прежде.

Копия хранится в `logs/private-application-test-backup` (доступ только владельцу), marker — `logs/private-application-test.active`. Результат PID/lock подтверждает запуск процесса; дополнительно проверьте ответ бота на `/try_apply` и отсутствие polling Conflict в свежем логе. Не запускайте второй polling с тем же токеном.

## Завершение тестирования и откат

`/exit_test` очищает сессию пользователя. Для удаления временной функции и возобновления автодеплоя выполните из каталога бота:

```sh
.venv/bin/python /path/private_application_test.py rollback
```

Откат сначала сверяет хеши изменённых файлов. При чужих правках он останавливается, чтобы не затереть их. Резервная копия сохраняется. Ключи и содержимое резюме installer не выводит.
