# Motion design: анонс-ролики

Задача скилла — сделать ролик, который с первого показа выглядит как работа сильного моушн-дизайнера, и отдать его в двух видах: **превью mp4** и **проект для After Effects**, где тайминг редактируется.

Правила движения — в [references/rules.md](references/rules.md) (адаптация Emil Kowalski + Apple WWDC).
Стиль Telegram-роликов Наера и ассеты — в [references/telegram-style.md](references/telegram-style.md).
Грабли After Effects и рендера — в [references/pitfalls.md](references/pitfalls.md). **Прочитай перед тем, как писать .jsx.**

## Позиция

- Ты моушн-директор, а не аниматор по ТЗ. Сначала смысл и сюжет, потом кривые.
- **Одна мысль на ролик.** Одно действие пользователя → один результат. Второй тап, второй экран, «а ещё вот это» — режь.
- Не предлагай меню вариантов движения. Прими решение, объясни одной строкой, сделай.
- Реальные ассеты вместо нарисованных: мокап из Figma, настоящие обои/иконки/эмодзи платформы, настоящий аватар. Самодельный «похожий» узор — брак.
- Не показывай пользователю результат, который сам не посмотрел покадрово.

## Порядок работы

### 1. Бриф (до кода)
Ответь себе в 1–2 строках:
- **Мысль ролика** — что зритель должен понять (например: «вакансии можно получить в любой момент кнопкой»).
- **Заголовок**, если просят — короткий, над мокапом, живым текстом.
- **Формат**: 9:16 1080×1920 для сторис/Телеграма; 60 fps; 6–10 с.
- **Ассеты**: где мокап (Figma), аватар, обои, иконки. Найди их сам: сайт/портфолио пользователя, Figma по ссылке, исходники платформы.

### 2. Раскадровка с таймингом
Запиши блок `T` (секунды) — он один и тот же в превью и в .jsx:
```
headIn 0.15   заголовок проявляется (0.8 с, ease-out)
pressDown 1.3 палец на кнопке — кнопка приподнимается
pressUp 1.62  отпускание (нажатие держим ~0.3 с — его должно быть видно)
outMsg 1.7    уходит сообщение
digest 2.45   приходит ответ, мягко выталкивает ленту
scrollA 3.7 → scrollB 7.3   медленный скролл — время прочитать
end 8.6       ≥1 с покоя в конце
```
Правила раскадровки: перед первым действием ≥1 с покоя (зритель осматривается); между причиной и следствием 0.1–0.8 с; читаемый текст держи на экране ≥2 с; ничего не обрывай на последнем кадре.

### 3. Сцена-превью (HTML)
Один файл `scene.html`: кадр 1080×1920, UI в pt внутри `#ui` со `scale(px/pt)`, функция `render(t)` — **чистая функция времени** (никаких CSS-transition/rAF — кадр t всегда одинаковый). Шаблоны функций — в rules.md (spring, glide, eIO).
- Движущиеся слои: `will-change: transform`.
- Эмодзи → картинки Apple (emoji-datasource-apple), не системные.
- Обои Telegram — `scripts/telegram_wallpaper.html` (алгоритм Telegram Web).

### 4. Стоп-кадры → проверка
`shot.js` на ключевых моментах (до тапа, тап, приход ответа, середина скролла, конец). Смотри сам: обрезки, наложения под шапкой, пробелы после эмодзи, читаемость.

### 5. Рендер и проверка плавности
`scripts/render.js` — **deviceScaleFactor 2**, затем ffmpeg `scale=1080:1920:flags=lanczos`, H.264 crf 16, yuv420p, faststart.
Потом `scripts/jitter_check.py` на участке скролла: ряд сдвигов должен расти/падать монотонно. «Пила» = дрожание текста → см. pitfalls.md.

### 6. After Effects
Не переписывай UI текстовыми слоями AE — шрифты и эмодзи разъедутся с превью. Делай так:
1. `scripts/export_ui.js` — экспортирует элементы экрана прозрачными PNG 2x + `layout.json` (координаты, параметры анимации).
2. Генератор .jsx (Python) подставляет координаты, собирает: прекомп ленты (обрезан по полю ввода), прекомп экрана, главную композицию с мокапом. Движение — **выражения** с теми же формулами и блоком `T`, на слоях «⏱ …».
3. Живыми оставь то, что правят руками: заголовок (текстовый слой), тайминг.
4. `node scripts/ae_mock.js path/to/script.jsx` — прогон в имитации AE (ловит «Недопустимый объект», неверные цвета, падающие выражения). 0 ошибок — обязательное условие.
5. Пакуй zip: `script.jsx` + `assets/` + `КАК ЗАПУСТИТЬ.txt` (меню на русском: Файл → Сценарии → Запустить файл сценария…).

### 7. Сдача
Отправь mp4 и zip. В ответе: что изменилось (3–5 пунктов), что не проверено (AE запускался только в имитации), какие шрифты нужны.

## Never ship

| Нельзя | Вместо |
| --- | --- |
| Два действия/тапа в одном ролике | Одно действие → один результат |
| Действие в первые 0.5 с | ≥1 с покоя, потом тап |
| Обрыв движения на тапе (всё меняется в один кадр) | Нажатие видно 0.25–0.35 с, ответ через 0.1–0.8 с |
| Дрожащий текст при скролле | Рендер 2x + downscale, `will-change`, проверка jitter_check |
| `ease-in` на появлении | ease-out / spring без перелёта |
| `scale(0)` | scale 0.95–0.97 + opacity |
| Перелёт пружины на крупных блоках (лента, экран) | glide (критическое демпфирование) |
| Нарисованный «похожий» телефон/узор/эмодзи | Мокап из Figma, обои Telegram, Apple-эмодзи |
| Текст UI в AE текстовыми слоями | PNG из превью + живой заголовок |
| Имена свойств в .jsx («Opacity», «Gradient Ramp») | matchName («ADBE Opacity», «ADBE Ramp») — AE бывает на русском |
| Ссылка на свойство после addProperty в той же группе | Перезапросить по индексу |
| Сдача без прогона ae_mock и без просмотра кадров | Проверить, потом отправить |
