# Грабли: After Effects, рендер, превью

Всё ниже — реально случалось. Проверяй каждый пункт.

## After Effects (ExtendScript)

1. **«Невозможно выполнить сценарий в строке N. Недопустимый объект».** После `addProperty()` в группе (shape group, Effect Parade, Mask Parade) ранее полученные ссылки на свойства этого слоя становятся недействительными. Добавил эллипс, потом обводку — ссылка на эллипс мертва. Решение: сначала добавь всё, потом перезапроси по индексу:
   ```js
   g.addProperty("ADBE Vector Shape - Ellipse");
   g.addProperty("ADBE Vector Graphic - Stroke");
   var el = g.property(1), st = g.property(2);
   ```
2. **Только matchName**, никаких отображаемых имён: у пользователя After Effects на русском. `"ADBE Opacity"`, `"ADBE Ramp"`, `"ADBE Drop Shadow"`, `"ADBE Gaussian Blur 2"`, `"ADBE Mask Atom"`, `"ADBE Time Remapping"`.
3. **Drop Shadow opacity** в скрипте — шкала 0…255, не 0…100. Цвет — `[r,g,b,a]` 0…1.
4. **Gradient Ramp**: форма `ADBE Ramp-0005` — выпадающий список: 1 = линейный, 2 = радиальный (индексы с 1).
5. **Векторная арифметика в выражениях** — `add(value,[x,y])`, не `value+[x,y]` (в JS-движке AE это конкатенация строк).
6. `addSolid(color)` — цвет `[r,g,b]` без альфы.
7. Расстояние/мягкость тени на масштабированном слое — в пикселях слоя: дели на масштаб.
8. Пути к ассетам: `new File($.fileName).parent.fsName + "/assets"`; если файла нет — понятная ошибка «положите папку assets рядом со скриптом».
9. ES3: нет `JSON`, `let`, стрелок, шаблонных строк. Данные из превью вшивай в .jsx генератором (Python).
10. Видео-слой длиннее исходника: `timeRemapEnabled = true`, выражение `time % (source.duration - source.frameDuration)`, затем `outPoint = T.end`.
11. Перед сдачей: `node scripts/ae_mock.js script.jsx` → «ошибок: 0». Имитация делает ссылки недействительными так же, как AE, считает все выражения на нескольких моментах времени.

## Превью (Playwright + Chromium)

1. **Дрожащий текст при скролле/масштабе.** Chromium округляет сдвиг слоя до целого пикселя → движение «пилой». Лечение: `deviceScaleFactor: 2` + уменьшение ffmpeg `scale=1080:1920:flags=lanczos`; `will-change: transform` на движущихся слоях. Проверка: `scripts/jitter_check.py` — ряд сдвигов должен быть гладким.
2. `render(t)` — чистая функция времени. Никаких CSS transitions/animations: скриншоты их не ждут.
3. Картинки (аватар-кадры, эмодзи) — дождаться `decode()` до первого кадра (`window.ready`).
4. Прозрачный экспорт элементов: `omitBackground: true` **и** прозрачный фон у `html` и `body`, иначе альфы нет.
5. Элементы выше верхнего края страницы не снять: увеличь viewport и сдвинь кадр вниз на время экспорта.
6. В flex-контейнере ведущий пробел текстового узла после `<img>` схлопывается — оборачивай текст в `<span>`.
7. backdrop-filter в PNG не экспортируется — в AE пересобери размытие корректирующим слоем (Gaussian Blur + маска с растушёвкой) и тонирующей плашкой.

## Стыки движений

1. **Рывок на стыке** — одно движение обрывается с ненулевой скоростью, другое стартует с нуля (или наоборот). Глаз видит «запинку», даже если каждое движение по отдельности плавное. Случай: толчок ленты подборкой (glide, нормированный на 1.1 с) обрывался на 2 px/кадр ровно когда стартовал скролл.
   - Каждое движение должно **начинаться и заканчиваться со скоростью ≈0**, либо стыки сшиваются по скорости.
   - Нормированная пружина `f(p)/f(1)` обрывается с остаточной скоростью — бери ω≥10: `1-exp(-10x)*(1+10x)`.
   - `1-(1-p)^4` стартует сразу на полной скорости — рывок в начале. Для толчка от покоя нужна пружина.
   - Между толчком и следующим движением — пауза 0.2–0.4 с (человек «посмотрел», потом свайпнул).
2. Проверка без рендера: посчитай позицию по формуле сцены на каждом кадре и выведи скорость вокруг стыков (`scripts/velocity_check.js` — пример). Скачок скорости на стыке >0.5 px/кадр — переделать.

## Процесс

- Каждое изменение сцены → стоп-кадры → посмотреть самому → только потом рендер.
- Рендер 2x на 516 кадров идёт ~10–15 мин — запускай в фоне и параллельно делай .jsx.
- Пользователь запускает AE сам; ты — нет. Всегда говори, что .jsx проверен только в имитации.
