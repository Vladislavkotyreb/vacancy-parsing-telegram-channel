# Правила движения

Адаптация [emilkowalski/skills](https://github.com/emilkowalski/skills) (animate, review-animations, apple-design; MIT, © 2026 Emil Kowalski) под промо-ролики. Важное отличие: Эмиль пишет про **живой UI**, где лимит ~300 мс. В ролике мы **объясняем** продукт — это его категория «Explanation / marketing», длительности могут быть длиннее. Но микродвижения внутри показанного UI (нажатие кнопки, появление сообщения) должны ощущаться как настоящий iOS — те же длительности, что в жизни.

## 1. Зачем движется

Каждое движение называет цель одним словом, иначе его нет:
- **Обратная связь** — интерфейс услышал нажатие (кнопка приподнялась, кольцо касания).
- **Пространственная связь** — откуда пришло/куда ушло (сообщение снизу, лента сдвигается).
- **Смена состояния** — было «новых нет» → стало «12 новых».
- **Объяснение** — показываем, как работает фича (весь ролик).
- **Delight** — только если всё остальное уже работает; не конфетти сверху.

«Красиво же» — не цель. Когда сомневаешься, удали движение.

## 2. Сюжет и хореография

- Одна мысль, одно действие, один результат.
- Причина → следствие: следствие начинается через 0.1–0.8 с после причины, не в тот же кадр и не через 2 с.
- Не всё сразу: группы входят с шагом 30–80 мс (stagger), крупные события разносятся на 0.5–0.8 с.
- Читаемый текст — на экране ≥2 с, но время на чтение даёт **пауза после скролла**, а не медленный скролл. Сам скролл — как свайп на iPhone: ~100–150 pt/с, 1.2–1.8 с, ease-in-out. Скролл 50 pt/с выглядит неестественно медленным (проверено на ролике «Вакансии сейчас»).
- В начале ≥1 с покоя, в конце ≥1 с покоя. Камера статична (стиль Наера).
- Движение подсказывает направление: новое сообщение приходит снизу и толкает ленту вверх.

## 3. Кривые

| Ситуация | Кривая |
| --- | --- |
| Появление / уход | ease-out: `cubic-bezier(0.23, 1, 0.32, 1)` или spring без перелёта |
| Перемещение по экрану (скролл, сдвиг ленты) | ease-in-out: `cubic-bezier(0.77, 0, 0.175, 1)` / glide |
| Нажатие (вниз) | ease-out 150–180 мс |
| Отпускание | spring с лёгким перелётом, ~0.5 с |
| Постоянное движение | linear |

**Никогда ease-in на появлении** — он тормозит ровно тот момент, на который смотрят.

Формулы (одинаковые в HTML и в выражениях AE):
```js
const eOut  = p => 1 - Math.pow(1 - p, 3);
const eIO   = p => p < .5 ? 4*p*p*p : 1 - Math.pow(-2*p + 2, 3) / 2;
// iOS-пружина: перелёт ~3%, для мелких элементов (кнопка, пузырь)
const spring = p => p<=0 ? 0 : p>=1 ? 1 : 1 - Math.exp(-8*p) * Math.cos(7*p);
// критически задемпфированная — для крупного (лента, экран): без перелёта
const glide = p => { if(p<=0) return 0; if(p>=1) return 1;
  const f = x => 1 - Math.exp(-6*x) * (1 + 6*x); return f(p) / f(1); };
const prog = (t, a, d) => Math.min(1, Math.max(0, (t - a) / d));
```

Пружины по Apple: по умолчанию **damping 1.0** (без перелёта); перелёт (~0.8) — только если действию предшествовал импульс (отпускание пальца, бросок). Перелёт на крупном блоке выглядит как дёрганье.

## 4. Длительности

| Элемент | Длительность |
| --- | --- |
| Нажатие кнопки (вниз) | 150–180 мс; держать нажатой 250–350 мс, чтобы было видно |
| Отпускание (spring) | 0.45–0.6 с |
| Появление сообщения / пузыря | 0.5–0.7 с (spring), opacity 0.12–0.18 с |
| Сдвиг ленты новым сообщением | 0.7–1.1 с (glide) |
| Заголовок | 0.6–0.8 с ease-out, подъём 20–30 px |
| Скролл по ленте | 1.2–1.8 с ease-in-out (~100–150 pt/с), потом пауза ≥1.5 с |
| Кольцо касания | опускается 0.3–0.35 с, держится пока палец нажат, гаснет 0.35 с |

## 5. Физика и происхождение

- Ничего не появляется из точки: старт `scale(0.95–0.97)` + opacity 0.
- Масштаб — от источника: исходящее сообщение растёт из правого нижнего угла, входящее — из левого нижнего; кнопка — из центра.
- Нажатая кнопка «приподнимается»: scale ×1.04–1.05 + тень (0 10 24 rgba(0,0,0,.18)) — в стиле Наера; возвращается пружиной.
- Вход и выход по одному пути.

## 6. Свойства

Только `transform` и `opacity` (+ `clip-path` при необходимости). Никаких `top/left/height` в анимации. `will-change: transform` на движущихся слоях. Не двигать детей через CSS-переменную родителя.

## 7. Материалы и типографика (Apple)

- Шапка/панели — полупрозрачный слой с размытием, лента уходит под него; вместо жёсткой линии — мягкий градиент-маска.
- Не класть светлое полупрозрачное на светлое полупрозрачное.
- Крупный заголовок: трекинг отрицательный (≈ −0.03 em на 70–80 px), leading ~1.05–1.1; вес Bold/Semibold. Основной текст — трекинг около 0.
- Системный шрифт платформы (SF Pro) прежде кастомного.

## 8. Ревью готового ролика

Смотри на 0.25× и покадрово, потом свежим взглядом. Ищи:
1. Обрывы: что-то меняется за один кадр без перехода.
2. Дрожание текста при скролле/масштабе (jitter_check).
3. Перелёт пружины на крупных блоках.
4. ease-in на появлении, scale(0).
5. Два события в один момент, когда их надо развести.
6. Нечитаемый текст: мелко, быстро уехал, под шапкой.
7. Не те ассеты: системные эмодзи вместо Apple, нарисованный телефон, фальшивые обои.

Формат замечаний — таблица «Было | Стало | Почему», потом вердикт: **Переделать** (обрыв, дрожание, не тот стиль) или **Ок**.

## Словарь (чтобы точно формулировать)

Stagger — каскад с задержкой; Spring — движение по физике пружины; Overshoot — перелёт за цель; Origin-aware — рост из источника; Rubber-banding — тугое сопротивление у края; Crossfade — растворение одного в другом; Morph — одна форма перетекает в другую; Push — новое выталкивает старое; Hold — пауза в позе; Ease-out / ease-in-out — быстрый старт и мягкая посадка / мягко с обеих сторон.
