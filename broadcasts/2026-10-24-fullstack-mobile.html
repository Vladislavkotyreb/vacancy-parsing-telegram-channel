Fullstack и мобильная разработка В боте появились разделы «Fullstack» и «Mobile»: Flutter, iOS, Android и React Native. Выбрать → /start, текущие подписки сохранятся Вакансии React Native теперь приходят только в «Mobile». Если подписаны на React и нужен React Native, отметьте его там Ещё в подборках теперь есть Хабр Карьера, а если вакансий больше 30, остальные открываются кнопкой «Показать остальные»
